# Whisky Note 🥃

ウイスキーを **分類（スコッチ／バーボン／ジャパニーズ など）** から調べ、飲んだ一杯を記録できるシングルページアプリ。
ビルド不要・依存ライブラリなしの素の HTML / CSS / JavaScript で動きます。

**公開ページ → https://hmsw-dev.github.io/whisky-note/**

## 機能

| 要件 | 実装 |
| --- | --- |
| 分類ごとの銘柄一覧 | トップの分類一覧 → 分類ページに所属銘柄をカード表示（8分類・59銘柄） |
| 分類ごとの特徴 | 分類ページに「この分類の特徴」「主な産地・スタイル」「おすすめの飲み方」「相性のよい食べ物」 |
| 銘柄ごとの特徴 | 銘柄ページに産地・タイプ・度数・参考価格・味わいチャート・テイスティングノート（香り／味わい／余韻） |
| 飲んだ／飲みたい／お気に入り登録 | 銘柄ページのボタンでトグル。マイページのタブで一覧 |
| 簡単なメモ | 飲んだ日・飲んだ場所・5段階評価・感想を1銘柄に何件でも。編集／削除可 |

そのほか、銘柄名・産地・味わいのキーワード横断検索、記録の JSON バックアップ／復元に対応しています。

## 使い方

`index.html` をブラウザで開くだけで動きます。ただし `file://` で開くと localStorage がうまく保存されない場合があるため、ローカルサーバー経由を推奨します。

```bash
cd whisky-note
python3 -m http.server 8777
# → http://localhost:8777/ を開く
```

## データの保存先

登録内容（飲んだ／飲みたい／お気に入り／メモ）は、**開いているブラウザの localStorage**（キー: `whisky-note:v1`）にのみ保存されます。サーバー送信は一切ありません。

- 別のブラウザ・別の端末には引き継がれません
- ブラウザのサイトデータを削除すると消えます
- 「マイページ → データ管理」から JSON で書き出し／読み込みができます

## ファイル構成

```
whisky-note/
├── index.html        # 画面の骨格とメモ入力ダイアログ
├── css/style.css     # 琥珀色のダークテーマ
└── js/
    ├── data.js       # 分類8件・銘柄59件のマスタデータ
    ├── store.js      # localStorage の読み書き
    └── app.js        # ハッシュルーティングと画面描画
```

## 銘柄・分類を追加するには

`js/data.js` を編集するだけです。

```js
// 分類を足す
CATEGORIES.push({ id, name, nameEn, country, emoji, summary, features[], regions[], pairing, howto });

// 銘柄を足す（cat には CATEGORIES の id を指定）
BRANDS.push({ id, cat, name, nameEn, sub, type, abv, price, tags[],
              profile: { peat, sweet, body, fruit }, // 各 0〜5
              desc, tasting: { nose, palate, finish } });
```

`id` は記録の紐付けキーなので、一度公開した銘柄の `id` は変更しないでください（変更すると過去のメモと紐付かなくなります）。

## 注意

記載の度数・参考価格は目安です。お酒は20歳になってから、適量をお楽しみください。
